# Dataset Directory

This directory separates raw, processed, and split data.

## Benchmarks

- Circles
- MNIST
- Fashion-MNIST
- CIFAR-10
- Simulated 16-QAM

## Important reproducibility rule

Raw externally obtained datasets are not silently modified.

Processed files are generated by the scripts in:

    scripts/data/

The simulated 16-QAM benchmark is generated by:

    src/data/qam16/simulator.py

Its channel parameters are explicit configuration variables. They
should not be interpreted as experimentally measured device data.
