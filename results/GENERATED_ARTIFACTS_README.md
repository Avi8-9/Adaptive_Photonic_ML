# Generated Research Artifacts

This directory contains machine-generated numerical artifacts supporting
the reproducibility structure of the manuscript.

The repository distinguishes three categories:

1. Numerical simulation outputs generated from explicitly defined models.
2. Analytical system-level calculations.
3. Synthetic reproducibility artifacts generated to exercise the complete
   data/figure/table pipeline.

The generated artifacts are not represented as newly fabricated laboratory
measurements.

Actual hardware measurements, when available, can replace corresponding
simulation files without changing the repository structure.
